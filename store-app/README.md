# ระบบร้านค้า POS & สต็อกสินค้า (Cloud v2)

ระบบขายหน้าร้าน (POS) สแกนบาร์โค้ดผ่านกล้องมือถือ และจัดการสต็อกสินค้าแบบ **Serverless (React + Supabase BaaS)**  
ไม่ต้องเปิดเครื่อง PC เป็นโฮสต์ตลอดเวลา ใช้งานได้จากทุกอุปกรณ์ผ่านอินเทอร์เน็ต พร้อมระบบบัญชีผู้ใช้และแยกสิทธิ์ร้านค้าเดียว (1 ร้านค้า • หลายบัญชี / หลายสิทธิ์)

---

## จุดเด่นของระบบใหม่ (v2)

- **ไม่ต้องใช้เครื่อง Host (Hostless Cloud):** ข้อมูลและระบบล็อกอินทำงานบน **Supabase** (PostgreSQL + Auth + Row-Level Security) ใช้งานผ่าน HTTPS ทันที (รองรับกล้องมือถือ iOS/Android ทุกรุ่น)
- **รองรับโหมดออฟไลน์ / สาธิตในตัว:** หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะทำงานด้วยข้อมูลสินค้าเดิม 68 รายการ และประวัติการขายจาก `backup.sql` ในเบราว์เซอร์ทันที
- **ระบบบัญชี & สิทธิ์ (`owner` vs `staff`):**
  - **เจ้าของร้าน (`owner`):** ดูต้นทุน/กำไรขั้นต้น, ยกเลิกบิล (Void) พร้อมคืนสต็อก, ลบสินค้า, จัดการบัญชีพนักงานและเปลี่ยนสิทธิ์, เชื่อมต่อ/อัปโหลดข้อมูลขึ้น Cloud
  - **พนักงานขาย (`staff`):** สแกนบาร์โค้ดขายสินค้า, คิดเงินทอน, เพิ่ม/แก้ไขสินค้า, ปรับจำนวนสต็อก, ดูยอดขายและบิลล่าสุด (ไม่สามารถดูต้นทุน/กำไร ลบสินค้า หรือยกเลิกบิลได้)
- **ระบบบิลขายและสต็อกจริง:**
  - รวมรายการสินค้าในตะกร้าเป็น 1 บิล (`orders` + `order_items`) พร้อมคำนวณเงินทอน (เงินสด / โอน QR PromptPay)
  - ตัดสต็อกสินค้าอัตโนมัติเมื่อชำระเงิน และแจ้งเตือนสินค้าใกล้หมด

## บัญชีทดสอบ (โหมดสาธิต / Local Mode)

เมื่อยังไม่เชื่อม Supabase สามารถกดเข้าสู่ระบบด่วนได้จากหน้า Login หรือใช้อีเมล/รหัสผ่านด้านล่าง:

| สิทธิ์ | อีเมล | รหัสผ่าน |
|---|---|---|
| **เจ้าของร้าน (`owner`)** | `owner@store.local` | `owner1234` |
| **พนักงานขาย (`staff`)** | `staff@store.local` | `staff1234` |

## การติดตั้งและใช้งานแบบ Cloud (3 ขั้นตอน)

### ขั้นตอนที่ 1: ตั้งค่าฐานข้อมูลบน Supabase
1. สร้างโปรเจกต์ฟรีที่ [supabase.com](https://supabase.com)
2. เปิด **SQL Editor** แล้วนำไฟล์ [`supabase/schema_and_seed.sql`](./supabase/schema_and_seed.sql) ไปวางทั้งหมดแล้วกด **Run**
   - สคริปต์จะสร้างตาราง `profiles`, `categories`, `products`, `orders`, `order_items` พร้อม RLS Policies และข้อมูลสินค้าเดิม 68 รายการ
   - **บัญชีแรกที่สมัครใช้งาน** จะได้รับสิทธิ์เป็น **`owner` (เจ้าของร้าน)** โดยอัตโนมัติ

> หมายเหตุ: หากต้องการให้พนักงานสมัครหรือสร้างบัญชีแล้วเข้าใช้ทันทีโดยไม่ต้องยืนยันอีเมล ให้ปิด **Confirm email** ในหน้า Supabase **Authentication → Providers → Email**

### ขั้นตอนที่ 2: เชื่อมต่อแอปกับ Supabase
เลือกทำวิธีใดวิธีหนึ่ง:
- **วิธี A (แนะนำสำหรับ Deploy):** ใส่ค่าในไฟล์ `.env` (ดูตัวอย่างจาก `.env.example`):
  ```env
  VITE_SUPABASE_URL=https://your-project-id.supabase.co
  VITE_SUPABASE_ANON_KEY=your-anon-key
  ```
- **วิธี B (ตั้งค่าผ่านหน้าเว็บ):** กดปุ่ม **"ตั้งค่า Cloud"** ที่มุมขวาบนของหน้า Login หรือในแท็บ **ตั้งค่า** แล้วกรอก URL กับ Anon Key จากหน้า **Supabase Settings → API**

### ขั้นตอนที่ 3: Deploy ขึ้น Cloud ฟรี (Vercel / Cloudflare Pages)
```bash
npm install
npm run build
```
- บน **Vercel**: ตั้ง Root Directory เป็น `store-app`, Build Command เป็น `npm run build`, Output Directory เป็น `dist` และใส่ Environment Variables `VITE_SUPABASE_URL` กับ `VITE_SUPABASE_ANON_KEY` (ไฟล์ `vercel.json` ถูกตั้งค่าไว้แล้ว)
- เปิดบนมือถือแล้วเลือก **"เพิ่มลงในหน้าจอหลัก (Add to Home Screen)"** เพื่อใช้งานแบบแอปเต็มหน้าจอ (PWA)
